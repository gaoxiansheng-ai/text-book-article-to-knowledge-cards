# Make Knowledge Cards（知识卡片生成）

## 概述

把一篇文章（用户直接粘贴的文本，或本地 Markdown/TXT 文件）提炼成 5～8 张知识卡片，方便复习和回顾。每张卡片只讲一个知识点，全部内容必须来自原文。

## 适用范围

**支持：**
- 用户粘贴的文章文本；
- 本地 Markdown（.md）或纯文本（.txt）文件，先用 read 工具读取完整内容，再按本技能处理；
- 中文、英文或其他语言的文本（卡片语言跟随原文）。

**暂不支持（直接说明无法处理，不要尝试绕路）：**
- 网页抓取：不访问 URL 去获取内容，只处理用户已提供的文本；
- PDF 文件；
- Anki 导入包；
- 图形界面或可点击的卡片应用（只输出 Markdown 文本，不创建文件、不生成图片）。

## 卡片格式

每张卡片必须按下面的模板输出，四个部分缺一不可：

```markdown
## 卡片 N：<标题>

- **核心知识**：<一句话说清这个知识点，能单独背下来>
- **简明解释**：<用平实的语言补充理解，避免堆砌术语，1-3 句>
- **例子 / 自测**：<一个来自原文的例子>，或 <一道答案能在原文找到的自测题>
```

规则：
- N 从 1 开始连续编号；标题用原文概念或自己概括的短语，尽量简短。
- 「核心知识」是这个知识点最重要的一个陈述；「简明解释」必须比「核心知识」有信息增量（展开背景、说清因果、拆解术语），而不是把同一句话换个说法。
- 「例子 / 自测」二选一：有合适的原文例子就用例子；否则用自测问题，答案必须能在原文中找到。自测题只出题、不附答案，把回想和核对留给用户。
- 整组卡片一次性输出为 Markdown 文本。

## 制作流程

1. **读取输入**：用户粘贴文本就直接使用；用户给文件路径就用 read 工具读取完整内容，文件较长时按章节分段读完，不要只看开头。
2. **提取候选点**：通读全文，标记所有候选知识点——定义、原理、因果关系、方法步骤、关键数据、重要结论。
3. **筛选与合并**：
   - 只保留值得一个没读过原文的人长期记住的知识；删掉广告、寒暄、铺垫、跑题内容和与主题无关的细节。
   - 同一知识点在文中多处出现时合并为一张卡片，取表述最完整的版本；观点雷同的内容只保留最有代表性的一条。
   - 一个知识点如果包含多个可独立成立的要点，拆成多张卡片。
4. **排序与定数量**：按重要性从高到低排列，最多 8 张。可靠知识点不足 5 个时，有几张出几张，并在最后用一句话说明为什么没有凑满 5 张。
5. **撰写卡片**：严格套用上面的模板。
6. **自检**：逐条对照「自检清单」检查，通过后再输出。

## 硬性要求

1. **只讲真正重要的知识**：宁缺毋滥。判断标准：这个知识点是否值得没读过原文的人记住、是否能在别处复用。
2. **一张卡片一个知识点**：不把多个独立知识点塞进同一张卡片，也不把同一知识点拆成多张卡片。
3. **删除重复内容**：同义反复的段落、前后重复的论述只取一次。
4. **不能编造**：卡片中的每句话都必须能在原文中找到依据。不补充原文没有的数据、结论、原因或例子；原文没说清的地方沿用原文措辞，不代替原文下结论；不确定时宁可少写。
5. **信息不足不强凑数量**：可靠知识点不足 5 个时如实输出更少的卡片并说明原因，不把不重要或重复的内容做成卡片充数。
6. **自测题的答案必须来自原文**：不能出一个原文无法回答的问题。

## 自检清单

输出前逐项检查：

- 每张卡片只讲一个知识点，卡片之间没有重复？
- 「核心知识」能否脱离上下文单独背下来？
- 「简明解释」与「核心知识」相比有没有信息增量？
- 「例子 / 自测」是否来自原文，或原文能回答？
- 卡片数量是 5-8 张，还是已经说明为什么更少？
- 有没有引入原文不存在的信息？

## 输出示例

原文片段：

> 番茄工作法由弗朗西斯科·西里洛在 1980 年代末提出。做法是：把工作分成 25 分钟一个的「番茄钟」，每个番茄钟只做一件事，结束后休息 5 分钟；每完成 4 个番茄钟，休息 15-30 分钟。研究表明，定时休息能延缓注意力下降，而频繁被打断是效率低下的主因。注意：25 分钟不是硬性规定，可以根据任务类型调整为 15-50 分钟。

对应卡片：

```markdown
## 卡片 1：番茄工作法是什么

- **核心知识**：把工作分成 25 分钟一个的「番茄钟」，每个番茄钟只做一件事，结束后休息 5 分钟。
- **简明解释**：用固定时长的工作块把任务切成小段，靠固定的节奏和休息来维持专注。
- **自测**：一个番茄钟多长时间？结束后休息多久？

## 卡片 2：长休息规则

- **核心知识**：每完成 4 个番茄钟，休息 15-30 分钟。
- **简明解释**：长休息只出现在每 4 轮之后，时长比轮间 5 分钟的短休息更长。
- **自测**：连续完成 4 个番茄钟后，休息时间是多少？

## 卡片 3：番茄钟时长可调

- **核心知识**：25 分钟不是硬性规定，可以根据任务类型调整为 15-50 分钟。
- **简明解释**：25 分钟只是默认值，时长是一个可以按任务类型调整的参数。
- **自测**：原文允许把番茄钟调到多长？

## 卡片 4：为什么有效

- **核心知识**：定时休息能延缓注意力下降，频繁被打断是效率低下的主因。
- **简明解释**：休息有助于注意力的保持，打断则会直接降低效率，两者从正反两面影响工作效果。
- **自测**：原文提到的两个影响效率的因素分别是什么？

## 卡片 5：提出者

- **核心知识**：番茄工作法由弗朗西斯科·西里洛在 1980 年代末提出。
- **简明解释**：这是一套诞生于 1980 年代末的时间管理方法。
- **自测**：番茄工作法的提出者是谁？在什么年代提出？
```

（示例正好提炼出 5 张卡片。正式输出时按原文实际情况给出 5-8 张；不足 5 张时如实说明原因。）
