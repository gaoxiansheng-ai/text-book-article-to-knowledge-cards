# make-knowledge-cards

一个可以开源的 Skill：把一篇文章（粘贴文本或本地 Markdown/TXT 文件）转换为 5～8 张知识卡片，方便复习与回顾。

## 项目解决什么问题

读长文章时，真正需要记住的往往只有几个关键点，但原文太长，复习时抓不住重点；随手做笔记又容易变成原文摘抄。本项目把一篇文章压缩成 5～8 张结构统一的知识卡片——每张卡片只讲一个知识点，能单独背诵、能用自测题检验，复习时只看卡片即可。

## 主要功能

- 每张卡片包含四个部分：**标题、核心知识、简明解释、例子或自测问题**
- 一张卡片只讲一个知识点；同一知识点多处出现时自动合并，删除重复内容
- 严格忠于原文：不编造、不补充原文没有的数据和结论
- 信息不足时不强行凑数量，如实输出更少的卡片并说明原因
- 卡片语言跟随原文语言（中文、英文均可）
- 输入支持粘贴文本或本地 `.md` / `.txt` 文件；输出为纯 Markdown 文本，不创建文件

暂不支持：网页抓取、PDF、Anki 导入、图形界面。

## 安装方法

本技能是纯文本（Markdown + YAML），无脚本、无依赖，安装就是把目录复制到 AI 工具的技能扫描目录：

```bash
# 以 Windows 为例，把本仓库的 make-knowledge-cards 目录复制到技能根目录
xcopy /E /I make-knowledge-cards <目标技能目录>\make-knowledge-cards
```

不同工具的技能目录：

| 工具 | 项目级（只对当前项目生效） | 用户级（对所有项目生效） |
|---|---|---|
| DeepSeek Harness | `<项目根>\.dsh\skills\` 或 `<项目根>\.agents\skills\` | `~\.dsh\skills\` 或 `~\.agents\skills\` |
| OpenAI 系工具（支持 SKILL.md 规范） | 其配置的 skills 目录 | 同左 |

DSH 会自动监视技能目录，复制完成后无需重启即可使用。`agents/openai.yaml` 为 OpenAI 系工具提供界面显示名称与简介。

## 使用方法

### 方式一：粘贴文本

把文章内容直接粘贴给 AI，并说明要做知识卡片：

> 请把下面这篇文章做成知识卡片：
>
> 睡眠并不是一个均匀的过程。整晚睡眠由多个周期组成……

### 方式二：本地 Markdown/TXT 文件

直接给出文件路径：

> 请把 notes\article.md 做成知识卡片

### 触发场景

当用户说「做成知识卡片」「提炼这篇文章的要点」「做闪卡式笔记」等，即使用本技能；输入是网址、PDF 或 Anki 文件时，技能会直接说明不支持。

## 输入输出示例

输入（原文片段）：

> 番茄工作法由弗朗西斯科·西里洛在 1980 年代末提出。做法是：把工作分成 25 分钟一个的「番茄钟」，每个番茄钟只做一件事，结束后休息 5 分钟；每完成 4 个番茄钟，休息 15-30 分钟。研究表明，定时休息能延缓注意力下降，而频繁被打断是效率低下的主因。注意：25 分钟不是硬性规定，可以根据任务类型调整为 15-50 分钟。

输出（知识卡片）：

```markdown
## 卡片 1：番茄工作法是什么

- **核心知识**：把工作分成 25 分钟一个的「番茄钟」，每个番茄钟只做一件事，结束后休息 5 分钟。
- **简明解释**：用固定时长的工作块把任务切成小段，靠固定的节奏和休息来维持专注。
- **自测**：一个番茄钟多长时间？结束后休息多久？

## 卡片 2：长休息规则

- **核心知识**：每完成 4 个番茄钟，休息 15-30 分钟。
- **简明解释**：长休息只出现在每 4 轮之后，时长比轮间 5 分钟的短休息更长。
- **自测**：连续完成 4 个番茄钟后，休息时间是多少？

## 卡片 3：番茄钟时长可调

- **核心知识**：25 分钟不是硬性规定，可以根据任务类型调整为 15-50 分钟。
- **简明解释**：25 分钟只是默认值，时长是一个可以按任务类型调整的参数。
- **自测**：原文允许把番茄钟调到多长？

## 卡片 4：为什么有效

- **核心知识**：定时休息能延缓注意力下降，频繁被打断是效率低下的主因。
- **简明解释**：休息有助于注意力的保持，打断则会直接降低效率，两者从正反两面影响工作效果。
- **自测**：原文提到的两个影响效率的因素分别是什么？

## 卡片 5：提出者

- **核心知识**：番茄工作法由弗朗西斯科·西里洛在 1980 年代末提出。
- **简明解释**：这是一套诞生于 1980 年代末的时间管理方法。
- **自测**：番茄工作法的提出者是谁？在什么年代提出？
```

更完整的规则（工作流、硬性要求、自检清单）见 [make-knowledge-cards/SKILL.md](make-knowledge-cards/SKILL.md)。
